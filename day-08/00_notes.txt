EIGHT DAY

For the eight day, we will be learning about the objects in JavaScript. We will be
focusing in the next topics within JS's objects:
    - What are they
    - How to create them
    - How to manipulate/modify them
    - Constructors
    - Parameters of a constructor 
    - OOP Paradigm
    - "For in" loop

In JavaScript, objects are variables than can store both: values and functions. Thus,
objects are one of the most important concepts in JavaScript since JS is an object
based paradigm. 

Conceptually they serve the same purpose, but they behave differently under the hood. 
Both this in JavaScript and self in Python are used inside an object's methods to refer 
to the specific instance of the object that is executing the code.
